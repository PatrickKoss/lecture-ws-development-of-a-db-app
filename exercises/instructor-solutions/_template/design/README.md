# Musterlösung für A0 bis A3

Diese Vorlage verwendet einen kommunalen Gerätepool als konkrete Referenz. Die generischen Namen `Resource` und `reference_items` bleiben erhalten, damit die Lösung zum Java-Starter passt.

- `domain-notes.txt` beantwortet A0 mit Begriffen, einer Annahme und zwei Geschäftsregeln.
- `er.mmd` ist das editierbare ER-Modell für A1. `er.svg` ist die gerenderte Fassung.
- `relations.sql` enthält die Relationsnotation für A2.
- `normalization.md` zeigt für A3 die funktionalen Abhängigkeiten, eine Änderungsanomalie und die verlustfreie Zerlegung bis 3NF sowie die BCNF-Prüfung.

Das API-Modell beschränkt sich bewusst auf die Stammdaten der Hauptressource. Kategorie, Standort, Ausgaben und Prüfungen bleiben getrennte Fachbereiche.
