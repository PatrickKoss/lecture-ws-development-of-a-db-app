Welche Arbeit soll Spring für uns wiederholen?

Server starten · Objekte bauen · Requests routen · JSON wandeln
Erwartet ist Infrastrukturarbeit. Typisch falsch sind Fachregeln und Datenmodell. Spring nimmt Mechanik ab, nicht Entscheidungen.

Vorbereitet und gemeinsam geschrieben

Spring-Vorlage
Vorbereitet Controller, Service, JPA-Entity und Fehlerformat
Gemeinsam Flyway-Schema mit JPA-Mapping und DTO-Vertrag abgleichen
Gemeinsam Repository-Adapter mit Spring Data für GET und POST ergänzen
Wir öffnen den C2-Starter der jeweiligen Domäne. Die Infrastruktur kompiliert bereits. Der Service kennt ein Repository-Interface. Der ORM-Adapter setzt dessen Methoden mit Spring Data JPA um. Flyway übernimmt den SQL-Stand aus B1; Hibernate ordnet Spalten den Entity-Feldern zu.

Ohne und mit Spring

Framework
Wir könnten alles selbst bauen. Das wäre für diesen Kurs nur Arbeit an der falschen Stelle. Das Framework standardisiert die wiederkehrenden Teile.

Dependency Injection

Abhängigkeitsinjektion
Dependency Injection bedeutet hier: Der Controller erhält seine Abhängigkeit. Er entscheidet nicht über deren Bau. Diese Trennung macht Austausch und Tests möglich.

C2-Starter · Spring Data JPA erzeugt die Implementierung
Spring Data erzeugt die Implementierung dieses Interfaces. Der ORM-Adapter übersetzt zwischen BookJpaEntity und dem Domain-Objekt Book. Der Service hängt vom fachlichen BookRepository ab. Für diese Abfragen brauchen wir weder SQL-Strings noch einen ResultSet-Mapper.

Der Adapter hält JPA im Repository

JpaBookRepository · C2
public Optional<Book> findById(long id) {
    return data.findById(id).map(BookJpaEntity::toDomain);
}

public List<Book> findAll() {
    return data.findAll(Sort.by("id")).stream()
        .map(BookJpaEntity::toDomain).toList();
}
exercises/instructor-solutions/library/spring · JpaBookRepository.java
data ist das injizierte SpringDataBookRepository. Hibernate erzeugt SELECT und mappt die Zeilen in BookJpaEntity. Unser Adapter übersetzt nur noch die Persistenzklasse in das unveränderliche Domain-Objekt Book. Die Sortierung nach ID macht die Listenreihenfolge ausdrücklich. Request durch die Anwendung

Datenweg
Der Controller delegiert an den Service. Der Service nutzt das Repository-Interface. Dahinter rufen ORM-Adapter und Spring Data Hibernate auf. Hibernate erzeugt SQL und verwendet weiterhin den JDBC-Driver. Auf dem Rückweg werden Domain-Objekte in Response-DTOs umgewandelt.

Swagger UI ist ein Client

Browser
Swagger UI liest OpenAPI und sendet echte HTTP-Requests. Es ist unser erster Client. Prüft Status und Body. Der grüne Response-Rahmen allein reicht nicht.
